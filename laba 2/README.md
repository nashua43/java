# Задание 1

## Задача 1. Точка координат

### Текст задачи

Создать сущность «Точка», расположенную на двумерной плоскости и описываемую координатами X и Y. Точка должна возвращать текстовое представление вида `{X;Y}`. Необходимо создать три точки с разными координатами и вывести их на экран.

### Алгоритм решения

1. Создать класс `Point` с двумя свойствами: `x` и `y`.
2. Создать конструктор, принимающий обе координаты.
3. Добавить методы получения и изменения координат.
4. Переопределить метод `toString()`, чтобы точка выводилась в формате `{X;Y}`.
5. В главном методе запросить координаты трёх точек с клавиатуры и вывести их.

# Задание 2

## Задача 1. Прямая (линия)

### Текст задачи

Создать сущность «Линия», которая описывается начальной и конечной точками. Для задания координат использовать сущность `Point`. Линия должна выводиться в формате `Линия от {X1;Y1} до {X2;Y2}`. Создать три линии. Третья линия должна начинаться там же, где первая, и заканчиваться там же, где вторая. После изменения координат первой и второй линий третья должна сохранять связь с соответствующими точками. Затем изменить координаты первой линии так, чтобы координаты третьей не изменились.

### Алгоритм решения

1. Создать класс `Line` со свойствами `start` и `end` типа `Point`.
2. Создать конструктор, принимающий две точки.
3. Создать третью линию, передав ей начальную точку первой линии и конечную точку второй линии.
4. Изменить координаты общих объектов точек. Так как линии хранят ссылки на одни и те же объекты, изменения будут видны в третьей линии.
5. Заменить начальную точку первой линии новым объектом. Третья линия останется связана со старым объектом точки.
6. Переопределить `toString()` для вывода линии.

# Задание 3

## Задача 1. Студент

### Текст задачи

Создать сущность «Студент», которая описывается именем и массивом целых оценок. Студент должен выводиться в формате `Имя: [оценка1, оценка2, ...]`. Создать Васю с оценками 3, 4, 5. Создать Петю и присвоить его полю оценок массив Васи. Заменить первую оценку Пети на 5 и вывести обоих студентов. Затем создать Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

### Алгоритм решения

1. Создать класс `Student` со свойствами `name` и `grades`.
2. Создать конструкторы с именем и массивом оценок, а также только с именем.
3. Для Пети присвоить ссылку на тот же массив, который принадлежит Васе. Это поверхностное копирование.
4. Изменить первую оценку Пети на 5. Изменение будет видно и у Васи, потому что оба студента используют один массив.
5. Для Андрея создать отдельную копию массива методом `clone()`.
6. Изменить оценку Васи и убедиться, что оценки Андрея не изменились.
7. Переопределить `toString()` для вывода имени и массива оценок.

# Задание 4

## Задача 1. Создаём точку

### Текст задачи

Изменить сущность `Point`: создавать точку можно только с указанием обеих координат X и Y. Создать точки с координатами `{3;5}`, `{25;6}`, `{7;8}` и вывести их.

### Алгоритм решения

1. Использовать класс `Point` с конструктором, который обязательно принимает две координаты.
2. Создать три объекта с координатами из условия.
3. Вывести объекты с помощью `toString()`.

## Задача 2. Создаём линию

### Текст задачи

Изменить сущность `Line`. Линию можно создавать с помощью двух объектов `Point` или с помощью четырёх чисел: `x1`, `y1`, `x2`, `y2`. Создать две линии из условия и третью линию, которая использует начальную точку первой и конечную точку второй.

### Алгоритм решения

1. Добавить в класс `Line` конструктор с двумя объектами `Point`.
2. Добавить второй конструктор с четырьмя координатами.
3. Создать линии и вывести их текстовое представление.
4. Для третьей линии использовать уже созданные объекты точек, чтобы изменения общих точек отражались в связанных линиях.

# Задание 5

## Задача 3. Длина линии

### Текст задачи

Изменить сущность `Line`, добавив возможность возвращать расстояние между начальной и конечной точками. Создать линию из точки `{1;1}` в точку `{10;15}` и вывести её длину.

### Алгоритм решения

1. В классе `Line` добавить метод `getLength()`, возвращающий целое число.
2. Вычислить разницу координат: `dx = x2 - x1`, `dy = y2 - y1`.
3. Использовать формулу длины отрезка: `sqrt(dx * dx + dy * dy)`, результат округлить до целого числа.
4. Создать линию из `{1;1}` в `{10;15}` и вывести длину.
